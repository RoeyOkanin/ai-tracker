# AI Tracker: מעקב צווארי בקבוק בשרשרת ה-AI

המערכת עוקבת אחרי 13 שכבות של שרשרת האספקה של AI (45 מניות), מזהה לאן הכסף זורם עכשיו, ואומרת מתי להיכנס לשכבה ומתי לשחרר אותה.

## איך זה עובד

1. **כל יום, אחרי סגירת וול סטריט** (GitHub Actions): מורידה מחירים, מדרגת את השכבות לפי חוזק ב-3, 6 ו-12 חודשים, קובעת את מצב השוק (ירוק / צהוב / אדום) ומריצה תיק נייר.
2. **בסוף כל חודש:** החלטה. 3 השכבות החזקות, 2 מניות בכל שכבה. שכבה שכבר מוחזקת נשארת כל עוד היא בטופ 5.
3. **כל יום, בדיקת יציאות:** סטופ נגרר, סגירה מתחת לממוצע 200, ומימוש שליש אחרי קפיצה חדה בשבוע.
4. **כל שבוע (מוצאי שבת):** Claude מוסיף נתונים מהעולם האמיתי (TSMC, יצוא שבבים מקוריאה, capex, אשראי) וקובע איפה צוואר הבקבוק ובאיזה שלב הוא. ראו [`docs/playbook.md`](docs/playbook.md).

## קבצים

| קובץ | מה יש בו |
|---|---|
| `config/universe.yaml` | השכבות והמניות |
| `config/rules.yaml` | החוקים (כל שינוי עובר בקטסט קודם) |
| `data/prices.csv` | מחירי סגירה מותאמים |
| `data/decisions_log.csv` | כל החלטה של המערכת, ברגע שהתקבלה. לא משכתבים אותו בדיעבד |
| `docs/data/latest.json` | תמונת המצב שהדשבורד מציג |
| `data/backtest/` | תוצאות הבדיקה ההיסטורית |

## אזהרות

- זה לא ייעוץ השקעות. המערכת נותנת מסגרת וציון, וההחלטה שלך.
- הבדיקה ההיסטורית מחמיאה: רשימת המניות נבחרה ב-2026, כשכבר ידוע מי הצליח. ההשוואה ההוגנת היא מול החזקה שווה של כל הרשימה.
- בחשבון רגיל כל מכירה ברווח חייבת ב-25% מס רווח הון.
